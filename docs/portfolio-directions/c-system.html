Typography

The decision is the story.

Body · Avenir Next / Arial · 16–20px · line height 1.6

A queue separates when work arrives from when it can be processed. That boundary is useful only if the consumer can recover safely.

Annotations · SFMono / Consolas · 12px · uppercase tracking .07em

System fonts keep these prototypes self-contained. A final font choice requires a Windows/Android fallback review.

Technical depth appears in the document flow. No modal, scroll lock or hover dependency. The control remains accessible without JavaScript.

Open disclosure

The label remains in place and the explanation appears beneath it. The relationship between control and content stays clear.

Navigate with Tab to inspect real focus. Use the Case study link to test navigation. Reduced-motion preferences disable smooth scrolling. No entry animation or delayed content.
